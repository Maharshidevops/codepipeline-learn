# src/hooks/

Shared React hooks used across pages and layout. These wrap the Zustand stores, ToastProvider context, router, and browser APIs so components consume one small hook instead of wiring those pieces themselves.

| File                          | Purpose                                                                                                                                                                                                                                                        |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useAuth.ts`                  | Convenience wrapper over `authStore` adding `isAdmin` / `isOrgAdmin` role helpers (mirrors the legacy base.html / \_subnav.html gates).                                                                                                                        |
| `useConfirm.ts`               | Returns `confirm(options) => Promise<boolean>` from ToastProvider; replaces the legacy `showConfirm` + delete-form confirms.                                                                                                                                   |
| `useIdleTimeout.ts`           | Idle-session timeout (45 min idle → warning dialog, 60 s grace → logout); timestamp comparison on a 5 s interval, cross-tab sync via BroadcastChannel, suspended while a research job is streaming.                                                            |
| `useIdleTimeout.test.ts`      | Unit tests for the pure `computeIdleAction` decision (none/warn/logout thresholds, wake-from-sleep straight to logout).                                                                                                                                        |
| `useLocations.ts`             | Location data for LocationSelector: bundled continent→country tree synchronously, states/cities via TanStack Query so geo rows share one cache.                                                                                                                |
| `useLockoutCountdown.ts`      | Login-lockout mm:ss countdown ticked every second, always recomputed from `lockedUntil - now` so clock skew / backgrounded tabs can't drift it.                                                                                                                |
| `useLockoutCountdown.test.ts` | Tests `formatCountdown` formatting and the countdown-to-unlock behavior with fake timers.                                                                                                                                                                      |
| `useModal.ts`                 | Tiny open/close/toggle state helper for `<Modal open={...}>`.                                                                                                                                                                                                  |
| `usePageTitle.ts`             | Sets `document.title` to "&lt;Page&gt; · Quralyst" from the deepest matched route `handle.title` on route change.                                                                                                                                              |
| `usePermissions.ts`           | `usePermissions` / `checkPermission` — single read path for permission gating; server permission map wins, legacy role derivation is the fallback when the map is absent.                                                                                      |
| `usePermissions.test.ts`      | Tests `checkPermission`: map overrides roles, legacy fallback, logged-out always false.                                                                                                                                                                        |
| `useProgressStream.ts`        | Module-scoped progress controller (`startProgress`/`stopProgress`/`minimizeProgress`/`maximizeProgress` + `useProgressBinding`) so the starting page and the app-wide ProgressModal/sidebar tracker drive one shared stream; sole caller of `progressService`. |
| `useProgressStream.test.ts`   | Tests the controller against the mock stream: `startProgress` seeds the store, `complete` flips finished + resultId.                                                                                                                                           |
| `useResolvedTheme.ts`         | Resolves the active ThemeId (incl. `auto`) to the concrete `'light' \| 'dark'` palette, re-resolving on theme switch or OS scheme flip; for JS consumers like ApexCharts.                                                                                      |
| `useStickyHeader.ts`          | Scroll-container ref for sticky table headers; replaces the legacy thead-cloning table-utils.js with native CSS sticky (`recalculate()` is a kept-for-parity no-op).                                                                                           |
| `useThemeTokens.ts`           | Live theme-token values read off `<html>` computed styles, re-read via MutationObserver on the `data-theme` attribute (ordering-proof vs. store-keyed effects).                                                                                                |
| `useToast.ts`                 | success/info/error + signup-success/logout toast helpers backed by ToastProvider.                                                                                                                                                                              |
| `useWizardDraft.ts`           | Persist/restore wizard form state to localStorage (the "Save Draft" action), generic over the RHF form shape; storage failures are swallowed (best-effort).                                                                                                    |

## Conventions

- `useIdleTimeout` deliberately compares timestamps on a coarse interval instead of long timers: background-tab throttling and laptop sleep can't produce a stale countdown — a wake past the deadline logs out on the first check. Activity while the warning dialog is open does NOT extend the session; only the explicit "Stay signed in" button does. Dev override: `localStorage quralyst.idleMs` / `quralyst.warnMs`.
- `useProgressStream` owns the active `ProgressSource` at module scope; components must read progress state from `progressStore`, never talk to `progressService` directly.
