# src/routes/

Routing layer for the SPA: the full `createBrowserRouter` tree, the central typed path builders, and the two route-guard components. Every navigable URL in the app is declared in `router.tsx` and built via `paths.ts` — never hand-write a URL string elsewhere.

| File                 | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `router.tsx`         | The full route tree. Top level: an `AuthLayout` branch (`/auth/*` pages), a `ProtectedRoute` → `AppLayout` branch (all authed routes, with `ErrorPage` as `errorElement`), and a `*` catch-all → `NotFoundPage`. Inside the authed shell: research wizards, `/previous-results`, the tabbed result workspace (`/quralyst-research/result/:resultId/{data,preview,manage,summary}` under `ResultLayout`, plus redirects from the four legacy per-view URLs), `/profile`, `/user-preferences`, `/faq`, billing pages, `/org/:orgSlug/*` under `OrgSettingsLayout`, and `/admin/*` gated by `RoleRoute role="is_admin"`. |
| `paths.ts`           | Central typed route builders (`paths.org.members(slug)`, `paths.result(id, tab)` etc.) — edit a path once here; param routes are functions, static routes are string constants, all `as const`.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `ProtectedRoute.tsx` | Auth gate wrapping the whole `AppLayout` branch; it waits for `authStore.hydrated` (the `GET /auth/me` session probe on mount) before deciding, then redirects unauthenticated users to login so a hard refresh / deep link doesn't bounce mid-probe.                                                                                                                                                                                                                                                                                                                                                                 |
| `RoleRoute.tsx`      | Role/permission gate (port of the Jinja `org_role`/`is_admin` checks) routed through `can()`; on denial it renders `ForbiddenPage` in place — no redirect, the user stays logged in and keeps their URL.                                                                                                                                                                                                                                                                                                                                                                                                              |

## Conventions

- **`handle: { title }`** on each route sets the browser tab title via `usePageTitle()` (called in `AppLayout`/`AuthLayout`, reads `useMatches()`).
- **Lazy chunks**: seven heavy pages (the three wizards, FV database/results, `ViewPreviousResultPage`, `SummaryPage`) are `lazy()`-loaded; everything else is imported eagerly. The `<Suspense>` boundaries live in `AppLayout` and `ResultLayout`, not here.
- **Legacy URL redirects**: `ResultTabRedirect` maps old `/quralyst-research/{previous-results,preview,manage-results,summary}/:resultId` bookmarks to the merged result workspace, preserving `:resultId`.
- **ProtectedRoute vs RoleRoute**: ProtectedRoute answers "is anyone logged in?" (redirects out); RoleRoute answers "may this user see this?" (renders 403 in place).
