# src/store/

Zustand stores for global client state: auth/session, UI chrome (sidebar + theme), and SSE processing progress. Components subscribe with hooks; non-React modules read/write via `useXStore.getState()`.

| File               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `authStore.ts`     | Auth/session store — `currentUser`/`isAuthenticated` plus a `hydrated` flag, with `login`/`logout`/`setUser`/`markHydrated`. The app boots unauthenticated and restores the session via `GET /auth/me` on mount (`App.tsx`); `hydrated` gates `ProtectedRoute` so a hard refresh waits for that probe. The session is a server-managed httpOnly cookie (never readable/stored client-side), so this store is pure state — no token is read by the request layer. |
| `progressStore.ts` | Active-processing/SSE progress state (process id/type, overall %, stage, per-file progress, minimized/finished flags) with `update(patch)`/`reset()`; written by the `useProgressStream` controller, read by ProgressModal and the sidebar tracker.                                                                                                                                                                                                              |
| `uiStore.ts`       | UI/chrome store — desktop sidebar collapse (with a `sidebarManual` flag: an explicit toggle persists to localStorage and overrides the ≈992–1200px responsive auto-collapse) and the active theme (persisted under `quralyst.theme`, default light).                                                                                                                                                                                                             |
| `uiStore.test.ts`  | Tests the theme slice: `setTheme` persists to localStorage, `cycleTheme` walks the theme registry in order and wraps.                                                                                                                                                                                                                                                                                                                                            |
