# src/lib/

Pure, non-React utilities: formatting, error normalization, logging/error-reporting seams, and small browser-API helpers. Nothing here renders or holds React state (the only React import is `flushSync` in `viewTransition.ts`).

| File                        | Purpose                                                                                                                                                                                                                                                                                                                                       |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `caseMapper.ts`             | Pure recursive snake_case↔camelCase key transforms for the FastAPI seam (`camelizeKeys`/`snakeizeKeys`); recurses arrays + plain objects only, leaves Dates/Files/FormData/class instances untouched. Not yet wired into http.ts (deliberate deferral — wire in if/when the backend returns snake_case; see `Phases/BACKEND-INTEGRATION.md`). |
| `caseMapper.test.ts`        | Tests recursive conversion, idempotency on already-camel keys, and that non-data values pass through.                                                                                                                                                                                                                                         |
| `datetime.ts`               | Timezone-aware date formatting via Intl (port of base.html's QuralystTimezone); effective tz = user's saved profile tz, else browser tz.                                                                                                                                                                                                      |
| `format.ts`                 | Number/currency/percent formatters; `formatCurrencyFromCents` because Stripe amounts are in cents.                                                                                                                                                                                                                                            |
| `logger.ts`                 | Ring-buffered app logger (200-entry cap, drop-oldest), console passthrough in dev; with `VITE_LOG_SHIPPING` on, batches POST to `/api/logs` every ~10 s and via `sendBeacon` on pagehide/hidden.                                                                                                                                              |
| `logger.test.ts`            | Tests buffering + drop-oldest cap, the batch flush contract against an MSW `/api/logs` handler, and the never-throws rule when shipping fails.                                                                                                                                                                                                |
| `normalizeApiError.ts`      | Maps an ApiError / unknown thrown value to one user-friendly message: 401 always → session-expired; short plain server text passes through; HTML/JSON bodies fall back to status-based messages.                                                                                                                                              |
| `normalizeApiError.test.ts` | Tests the 401 rule, short-message passthrough, HTML/JSON skip, and the generic fallback for unknown shapes.                                                                                                                                                                                                                                   |
| `password.ts`               | Password policy (min 8, number, special, upper, lower) — verbatim port of the legacy JS/Python policy; shared by live requirement hints and Zod validation.                                                                                                                                                                                   |
| `reportError.ts`            | Env-gated error-reporting seam: `initErrorReporting()` dynamically imports `@sentry/react` only when `VITE_ERROR_REPORTING_DSN` is set (own lazy chunk, zero cost otherwise) and scrubs PII in `beforeSend`; `reportError()` never throws.                                                                                                    |
| `toastBus.ts`               | Register/emit bridge so non-React code (QueryClient global error handler, http 401 hook) can raise an error toast through the single ToastProvider; emits before a provider mounts are silently dropped.                                                                                                                                      |
| `viewTransition.ts`         | `withViewTransition(update)` — wraps a state-driven DOM swap (wizard steps) in `document.startViewTransition` + `flushSync`; plain update on unsupported browsers or `prefers-reduced-motion`.                                                                                                                                                |

## Conventions

- Files here must stay React-free (pure functions / module state only) so they can be imported from stores, services, and tests without a render context.
- `logger.ts` hard rules: it must never throw or loop — shipping failures are swallowed, never logged through itself; it uses plain `fetch` (not `http()`) to avoid auth/CSRF coupling and recursion into error handling; never log tokens, passwords, API keys, or result data.
- `reportError.ts` call sites never know whether reporting is on; with no DSN set, Sentry is never imported at all.
